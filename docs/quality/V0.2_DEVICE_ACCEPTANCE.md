   - `<PAGES_URL>/public/manifest.webmanifest`：`scope`、`start_url` 均解析到本專案根路徑
   - `<PAGES_URL>/sw.js`：HTTP 200、JavaScript MIME；瀏覽器實際控制範圍也須檢查
   - `<PAGES_URL>/src/app.js`、`<PAGES_URL>/src/analysis/explain.js`：HTTP 200、非 GitHub 404 頁

4. 將**實際成功的** Pages URL、GitHub Pages deployment run ID、`__acceptance.json` 內容及 UTC／台灣測試日期補入本報告，再開始手機測試。若尚未成功，所有需要該網站的手機案例維持 **BLOCKED**。

> **更新測試前提：** SW 的 `CACHE_VERSION` 必須在有正式驗證的新 shell 內容時更新。欲驗證「更新」須部署兩個**有版本差異**且都經驗證的候選 SHA，記錄更新前後碼與 Cache Storage；不能把同一份原始碼重開網站假稱 SW 更新成功。更新不得刪除既有 v3 記錄／v1 原始字串。
