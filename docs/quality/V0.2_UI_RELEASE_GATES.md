## 自動化

```bash
npm run check
# 在已審核的 V0.2 UI source（或 CI 的 PR #21 固定 SHA）執行：
python -m pip install playwright==1.56.0
python tests/browser/release-gates.py --screenshots /tmp/tmt-release
python tests/pwa/release-gates.py --screenshots /tmp/tmt-release
```

`.github/workflows/v02-ui-release-gates.yml` 以 Ubuntu 24.04、Node.js 22、Python 3.12、實際 Google Chrome/Playwright 1.56 測試 GitHub Pages 子目錄 `/taiwan-mahjong-trainer/`。CI 存確切 Commit SHA、瀏覽器版本、截圖及執行紀錄至 `independent-ui-release-evidence` Artifacts。任何必要測試失敗即 Job fail，不以 TODO/skip 掩蓋。

| 項目 | 增強後強制驗證 |
| --- | --- |
| 何切 | 固定 seed 產題、玩家按鍵作答；逐候選檢查畫面 shanten/kinds/copies/draws、最佳標記與 ranking、解說句子/分數、v3 快照 |
| 並列最佳／錯誤答案 | 真正找出兩張以上相同最佳的題目並點選；另選較高向聽並驗證 grade=improve |
| 聽牌與多面聽 | 16 張真題、複選、正確與故意誤選；expected/missed/extra、剩餘張數和 Record 完整比對 |
| UI 狀態 | 三難度切換、下一題清空狀態、焦點/Home/End、390px 點擊區域與版面溢出 |
| 資料 | 4 次作答後刷新讀回，正式下載 JSON 必須等於原始儲存；Node 覆蓋重複題目/作答 ID、壞 JSON、未知 schema、竄改分數、quota blocked、v1 原始值不變 |
| PWA | 真正切斷網路後從新分頁開啟，三題型可用、離線作答、離線刷新與歷史；核對 SW scope、manifest、必要資源預快取 |
| 更新 | 只修改**暫存伺服器副本**的 SW/cacheVersion 與 core bytes，驗新快取包含新演算法、舊 shell 清理、非本 app 的 cache 與 v3 歷史保留 |

用測試專用 UUID 控制題目種子，不 patch 判分函式。UI 與 canonical API 的核對**不能代替**獨立數學 Oracle，正式放行需兩者同時通過。Issue #13 仍須管理員在 GitHub 設 Required status checks；workflow 存在不代表 Branch Protection 已啟用。
