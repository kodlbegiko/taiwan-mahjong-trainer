# 台麻訓練所 · 技術與教學架構

## 產品北極星

讓真人玩家能持續改善出牌決策品質，而不是只看對局勝率。

## v0.1 演算法

對 17 張非花手牌的每種不同牌 `d`：

1. 移除 `d`，得到 16 張牌。
2. DFS 搜尋一般五面子一將最小向聽數 `S(d)`。
3. 對每一種剩餘可摸牌 `t`，比較 `S(hand16 + t)` 與 `S(d)`。
4. 若小於原向聽，則 `t` 是有效進張；數量為四減去自己的已知牌數（可另扣除明牌）。
5. 排序：優先低向聽，再優先較多進張張數及種類。

此演算法是**結構性牌效率**，不代表最大胡牌機率、更不代表最大預期台數或最小放槍損失。

## v0.2 目標

實現正確顯示 16 張向聽、有效進張，以及固定題庫 goldens；擴充公開副露狀態。加入至少一套與本實作獨立的參考演算法，用生成測試驗證正確性。

## v0.3 攻防目標

進場資訊：自己手牌、巡目、已見棄牌、吃碰槓、尚餘活牌。區分「邏輯必然安全」和「統計估計風險」，並提供風險估計校準曲線、對戰模擬驗證。

## v0.4 複盤目標

建立 `MatchRecord`、`Turn`、`PlayerView`、`Action`、`RuleProfile` JSON schema；導入完整資訊與觀看資訊隔離、局面重播與逐巡評估；隱藏資訊不可洩漏給即時策略器。

## 客戶端隱私

所有練習題與判定在瀏覽器執行，紀錄存於 localStorage；目前不傳送個人資料到伺服器。
